# Ankra desktop app

This repository holds release binaries of the Ankra desktop app for Windows and Linux. There is no code here.

Download the app at [ankra.ai/download](https://ankra.ai/download), which also lists the iPhone, iPad, Mac and Android apps, the `ankra` CLI and the MCP server. Each version is attached to a [release](https://github.com/ankraio/ankra-desktop/releases) here, with a `SHA256SUMS` file to check the downloads against.

The app's source is in a private Ankra repository. To report a problem, email hello@ankra.ai or use [support.ankra.app](https://support.ankra.app).
